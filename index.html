Especialidad Habilidades Proyectos

¿De qué trata la especialidad?

La especialidad de Programación permite aprender a crear páginas web, aplicaciones y sistemas informáticos. También se trabaja con bases de datos y herramientas para resolver problemas usando tecnología.

Habilidades que se desarrollan

  • Programación con Python
  • Creación de páginas web con HTML y CSS
  • Manejo de bases de datos y SQL
  • Uso de Git y GitHub
  • Detección y solución de errores
