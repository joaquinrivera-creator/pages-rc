Especialidad de Programación

¿De qué trata?

La especialidad de Programación enseña a crear páginas web, programas y sistemas usando diferentes herramientas. También ayuda a aprender a resolver problemas mediante la tecnología.

Habilidades que se desarrollan

  • Crear páginas web con HTML.
  • Diseñar páginas con CSS.
  • Programar con Python.
  • Trabajar con bases de datos.

Ejemplos de proyectos

  1. Una página web informativa.
  2. Un videojuego sencillo.
  3. Un sistema para registrar productos.
